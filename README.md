# Nueva web Ingeniería Joaquín Rocamora · Propuestas de diseño

Tres propuestas alternativas de diseño para la **página de inicio** de la nueva web de
Ingeniería Joaquín Rocamora, como referencia para el equipo de TARSA.

Las tres usan el **mismo contenido** (textos, cifras y fotografías) que la web en desarrollo;
solo cambia el diseño. En todas se mantiene el **dorado del logo (#E9AC00)** como color de realce
y el azul marino corporativo (#082440).

| | Propuesta | Idea |
|---|---|---|
| 1 | [Corporativa luminosa](propuesta-1/) | La más cercana a la identidad actual, más limpia y con más aire. Fondos claros, tarjetas, dorado en botones y cifras. |
| 2 | [Arquitectónica editorial](propuesta-2/) | Tono premium tipo estudio de arquitectura: serif elegante en titulares, composición tipo revista, líneas finas doradas. |
| 3 | [Técnica con contraste](propuesta-3/) | Más impacto visual: secciones oscuras y claras, guiños a planos de ingeniería (rejilla, cotas), dorado como único realce. |

## Cómo verlas

- **Online:** https://carlosmm999.github.io/WEB-IJR-TARSA/ (portada con las tres opciones).
- **En local:** descargar el repositorio (botón *Code → Download ZIP*) y abrir `index.html` en el navegador.

Se recomienda verlas también en el móvil o estrechando la ventana del navegador: todas son responsive.

## Notas

- Son maquetas en HTML/CSS estático, no la web final. Los enlaces internos y el formulario no están operativos.
- Se pueden combinar elementos de distintas propuestas.
- Estructura: `propuesta-N/` (HTML + CSS de cada opción), `assets/img/` (logos y fotos), `assets/js/main.js` (menú móvil, contadores y animaciones).
